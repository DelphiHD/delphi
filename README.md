# delphi

HD Reports — a paid web app delivering personalized Human Design readings.

Start by reading `CLAUDE.md` (rulebook) and `HD-Reports-Master-Plan.md` (build plan). On a fresh clone:

```sh
git config core.hooksPath .githooks
cp .env.local.example .env.local   # then fill in real values
npm install
npm run dev
```

Doc map: `docs/CONTEXT.md`, `docs/INTENT.md`, `docs/IDENTITY.md`, `docs/VOICE.md`, `docs/ARCHITECTURE.md`, `docs/DECISIONS.md`, `docs/STACK_PORTED.md`.
